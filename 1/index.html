Single Scale Alignment

The three colour channels need to be lined up to produce a colour image. This can be done by sliding the channels along the horizontal and vertical axes until they match up. Euclidian Distance (ED) and Normalized Cross Correlation (NCC) are two quantitative metrics that can indicate how well aligned two channels are.

First, I crop out the outer 10% of each channel to remove the borders and ensure I am only using the main image content for alignment. Then, I slide the green channel along both axes, testing the alignment metric against the blue channel for every possible pixel displacement within the range [-15 15]. Then, I do the same with the red channel, sliding it and comparing it with the blue channel.

Multi-Scale Alignment

Large images have many pixels to compare, which takes a long time. To restore the large images in a reasonable amount of time, we need a more efficient approach. This is where multi-scale image pyramids come in.

By downsampling the image, I can quickly get a rough alignment. Then, the higher resolution image can be used to fine-tune the alignment within a smaller range of displacements. By creating a "pyramid", of several different scales of the same image, I can progressively improve the alignment without too much computational burden.

Downsampling

To obtain different image scales, I simply subsample the original channels. Every odd-numbered pixel along each axis is discarded, providing a downsampled image with half the original width and height. This is repeated until I obtain an image with a height or width below 64 pixels. This size is not computationally expensive to work with, and further subdivisions were not found to be neccessary during evaluation. This process results in a multi-scale image pyramid. Note that the outer 10% of each image is cropped out, just like it is for the single scale approach.

Alignment

With the multi-scale image pyramid complete, I can begin aligning the image, starting with the lowest resolution. Initially, I follow the same approach used for single scale alignment, but with a smaller range of displacement values. A displacement range of [-3, 3] was found to work well without increasing the computation time too much. After the current scale is aligned, I switch to the next highest scale. Then, I repeat this process using the previous scale's alignment as an approximate starting point. Eventually I reach the highest scale, i.e. the original image, and obtain a fully aligned high-resolution image.

Example

Below is a set of reconstructions for each pyramid scale of the image 00804v.jpg. At each stage, the resolution doubles and the alignment is fine-tuned by a maximum of 3 pixels. The final image on the right is high-resolution and fully aligned. This example uses the ED metric to judge alignment.
